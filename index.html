Homelab

Self-hosted network & pentesting lab — Traefik, AdGuard Home, Uptime Kuma, Kali / Metasploitable2

A home server environment I run and administer to get hands-on practice with the networking and sysadmin work that underlies everything else I build. It hosts a reverse proxy (Traefik), network-wide ad and tracker blocking (AdGuard Home), and uptime / service monitoring (Uptime Kuma), all configured, maintained, and troubleshot by hand rather than through a pre-built dashboard.

Alongside the administration side, I use the lab as an isolated range for offensive security practice — running Kali Linux against a Metasploitable2 target to work through enumeration, exploitation, and post-exploitation in a safe, contained network. Every exercise gets written up afterward as a short pentest-style report: scope, findings, evidence, and remediation, mirroring how real engagements are documented rather than just collecting terminal output.

Design decision

I treat the lab as two linked halves — a "blue" side I defend and keep running (DNS, reverse proxy, monitoring) and a "red" side I attack on purpose (Kali vs. Metasploitable2). Running both on the same network forces me to think about findings the way an actual admin would have to: not just "how do I break this" but "what would I tell myself to fix."

Linux administration Traefik (reverse proxy) Nginx (web service) AdGuard Home Uptime Kuma Kali Linux Metasploitable2 Report writing

PortPatrol

Port scanner & Linux hardening utility — Python

Scans a configurable port range with a multithreaded, thread-safe queue, then cross-checks every open port against the kernel's live socket table (ss -tunlp) to identify the exact process behind it. Presents remediation options — block, kill, upgrade, deploy fail2ban, or skip — and runs the right command for the detected distro.

Python Threading ufw · firewalld · iptables

HTTP security header auditor — Python CLI

Checks a target URL's HTTP response against key security headers — CSP, Strict-Transport-Security, X-Frame-Options, X-Content-Type-Options, and Referrer-Policy — and prints a clean pass/fail table of what's missing or misconfigured.
